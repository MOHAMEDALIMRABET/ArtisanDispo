# 💰 Comment fonctionne le paiement sur ArtisanDispo ?

**Version simple pour artisans et clients**

---

## 👷 POUR LES ARTISANS

### ❓ "Quand est-ce que je reçois mon argent ?"

Le paiement se fait en **2 étapes** :

```
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│  1️⃣ FIN DES TRAVAUX                                         │
│     ↓                                                        │
│  2️⃣ VALIDATION CLIENT (ou automatique après 7 jours)        │
│     ↓                                                        │
│  3️⃣ 💰 ARGENT DANS VOTRE "CHIFFRE D'AFFAIRES"              │
│     ↓ (IMMÉDIAT - 0 seconde)                                │
│     ↓                                                        │
│     ┌────────────────────────────────────┐                  │
│     │  Vous avez maintenant le choix :   │                  │
│     │                                     │                  │
│     │  A) Laisser l'argent s'accumuler   │                  │
│     │     pour un virement groupé        │                  │
│     │                                     │                  │
│     │  B) Demander un virement           │                  │
│     │     maintenant vers votre banque   │                  │
│     └────────────────────────────────────┘                  │
│     ↓                                                        │
│  4️⃣ VOUS DEMANDEZ UN VIREMENT                               │
│     ↓                                                        │
│  5️⃣ VIREMENT SEPA VERS VOTRE BANQUE                         │
│     ⏱️ Délai : 1 à 3 jours ouvrés                           │
│     ↓                                                        │
│  6️⃣ 💰 ARGENT SUR VOTRE COMPTE BANCAIRE                     │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### ⏱️ Combien de temps ça prend ?

| Étape | Délai |
|-------|-------|
| Validation travaux → Chiffre d'affaires | **Immédiat** (0 seconde) |
| Demande de virement → Traitement | **0 à 6 heures** (automatique) |
| Virement SEPA → Compte bancaire | **1 à 3 jours ouvrés** |

**TOTAL** : Entre 1 et 3 jours après votre demande de virement

### 💡 Astuce

Vous pouvez **cumuler plusieurs paiements** avant de demander un virement groupé :

```
Exemple :
• Lundi : Travaux client A validés → +800€ Chiffre d'affaires
• Mercredi : Travaux client B validés → +1500€ Chiffre d'affaires
• Vendredi : Travaux client C validés → +2200€ Chiffre d'affaires

Total Chiffre d'affaires : 4500€

→ Vous demandez UN SEUL virement de 4500€
→ Économie de frais bancaires
→ Meilleure gestion trésorerie
```

```
│     🔔 Vous recevez une notification                        │
│     ↓                                                        │
│  2️⃣ VOUS AVEZ 7 JOURS POUR DÉCIDER                          │
│     ↓                                                        │
│     ┌────────────────────────────────────┐                  │
│     │  Vous avez 3 options :              │                  │
│     │                                     │                  │
│     │  A) ✅ Valider les travaux         │                  │
│     │     → Argent libéré immédiatement   │                  │
│     │                                     │                  │
│     │  B) ⚖️ Signaler un problème        │                  │
│     │     → Médiation ArtisanDispo        │                  │
│     │     → Argent reste BLOQUÉ           │                  │
│     │                                     │                  │
│     │  C) ⏱️ Ne rien faire               │                  │
│     │     → Validation auto après 7 jours │                  │
│     └────────────────────────────────────┘                  │
│     ↓                                                        │
│  3️⃣ APRÈS VALIDATION                                        │
│     ↓                                                        │
│     💰 L'artisan recevra son paiement                       │
│     ↓                                                        │
│  4️⃣ VOUS POUVEZ LAISSER UN AVIS                             │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 🔒 Votre protection

**Votre argent reste EN SÉCURITÉ** jusqu'à ce que :
- ✅ Vous validiez les travaux manuellement
- ✅ OU validation automatique après 7 jours

En cas de problème :
- ⚖️ Vous signalez un litige
- 🛡️ Argent BLOQUÉ pendant médiation
- 👨‍⚖️ Équipe ArtisanDispo intervient sous 48-72h
- ⚖️ Résolution : remboursement partiel/total ou nouveaux travaux

### ❓ "Pourquoi 7 jours de délai ?"

**Protection DOUBLE** :
1. **Pour VOUS** : Temps de vérifier la qualité des travaux
2. **Pour l'ARTISAN** : Protection contre clients absents

Si vous êtes satisfait, vous pouvez valider **immédiatement** (pas besoin d'attendre 7 jours).

## 💳 Schéma de paiement

### Vision globale

```
┌─────────────────────────────────────────────────────────────┐
│                       SÉQUESTRE                              │
│                    (Argent bloqué)                           │
│                                                              │
│  Client paie →  [💰 Argent sécurisé]  ← Artisan attend     │
│                                                              │
│                         ↓                                    │
│                  Fin des travaux                             │
│                         ↓                                    │
│                  Validation client                           │
│                  (ou auto 7 jours)                           │
│                         ↓                                    │
│                         ↓                                    │
│         ┌───────────────┴────────────────┐                  │
│         ↓                                 ↓                  │
│   💰 Portefeuille                    💵 Commission           │
│      ArtisanDispo                       Plateforme           │
│    (92% du montant)                    (8% du montant)       │
│         ↓                                                    │
│   Artisan demande                                            │
│   virement bancaire                                          │
│         ↓                                                    │
│   🏦 Compte bancaire                                         │
│      artisan                                                 │
│   (1-3 jours SEPA)                                          │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### Exemple concret

**Devis accepté : 1000€ TTC**

```
1. Client paie 1000€ → Séquestre ArtisanDispo

2. Travaux réalisés

3. Client valide

4. Répartition instantanée :
   • 920€ → Portefeuille artisan (Chiffre d'affaires)
   • 80€ → Commission ArtisanDispo

5. Artisan demande virement de 920€

6. Virement SEPA initié : 1-3 jours

7. Artisan reçoit 920€ sur son compte bancaire
```

## ❓ QUESTIONS FRÉQUENTES

### Pour les ARTISANS

**Q1 : Pourquoi je ne reçois pas l'argent directement sur mon compte bancaire ?**  
R : Pour vous permettre de **cumuler plusieurs paiements** avant de faire un seul virement groupé. Économie de frais bancaires !

**Q2 : Je peux demander un virement de combien minimum ?**  
R : Minimum 10€ (évite les micro-virements inutiles).

**Q3 : Combien coûte un virement ?**  
R : **Gratuit** - ArtisanDispo prend sa commission (8%) lors de la libération du séquestre, pas sur les virements.

**Q4 : Je peux annuler un virement en cours ?**  
R : Oui, si le statut est encore "en_attente" (avant traitement par la Cloud Function). Une fois traité, c'est irréversible.

---

### Pour les CLIENTS

**Q1 : Mon argent est-il vraiment sécurisé ?**  
R : OUI - Argent bloqué sur compte séquestre ArtisanDispo. L'artisan ne peut pas y toucher avant votre validation.

**Q2 : Que se passe-t-il si je ne valide pas sous 7 jours ?**  
R : Validation **automatique** pour protéger l'artisan. Si vous êtes absent, l'artisan sera quand même payé (après délai raisonnable).

**Q3 : Je peux valider avant 7 jours ?**  
R : OUI - Vous pouvez valider **immédiatement** si vous êtes satisfait. Le délai de 7 jours est un MAXIMUM.

**Q4 : L'artisan reçoit l'argent immédiatement après validation ?**  
R : Oui, l'argent est libéré dès que vous validez. L'artisan pourra le recevoir selon ses modalités de paiement.
